# Drop competitor images here

- Gemini images go in ./gemini/   (e.g. gemini/watch.avif)
- ChatGPT images go in ./chatgpt/ (e.g. chatgpt/watch.avif)
- Then set the matching `src` in data/products.ts (the only file you need to edit).
- Leave it blank and the site shows the "waiting for upload" sticky instead.
