✧ ( the working playbook )

One reference.
A repeatable process.

Written from the TESSEL exercise. Another designer should reach the same kind of result by following it. This is a first version; it improves after someone else tries it.

#StepDo thisTime (rough estimate)
1BriefWrite objective, audience, placements, must-hold details.5 min
2SourcePick one clean product photo you have the licence for. Note the licence and URL.5 min
3BrandAdd the label or mark on the source image first. Check it at 100% zoom.1 min
4GenerateUse the source as the reference. Prompt: "place this exact [product] ... keep [pattern] and [label]". Change one thing per scene.1 min per scene
5CheckCompare to the source: shape, pattern, label, colour. Mark pass / close / fail.3 min
6FixInpaint anything wrong (stray text, label). Outpaint if the placement needs more room.2 min each
7Repeat testRun the same prompt 4 more times. Note how many hold. If labels fail, add them as a second reference or finish by hand.2 min
8CropCut 16:9, 4:5, 1:1, 9:16 around the focal point. Check text legibility at 120px.5 min
9Hand offName files, export to the spec table, note tool and prompt per file.5 min

QA checklist

  • Product shape, pattern and label match the source
  • No real brands, readable third-party text or logos in the scene
  • Mobile crop keeps the focal point
  • Headline still readable at thumbnail size
  • Concept / spec label present, licence noted
