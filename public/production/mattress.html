concept / spec work

Brief to result

Invented brief, written the way a marketing partner would send it.

Brief (fictional)

Objective: lift add-to-cart on the SOMNA mattress PDP and give paid social 3 ad angles.
Audience: 28-45, replacing a mattress, buys online, cares about feel and trial period.
Placements: PDP hero (16:9 desktop, 4:5 mobile), 1:1 and 9:16 social, wide banner.
Must hold: hexagon quilted top, dark knit side panel, white SOMNA side label.

Decisions I made

  1. Daylight bedroom on a platform base for the PDP hero: whole mattress visible, label on the side panel.
  2. Warm evening room for lifestyle: comfort, not specs.
  3. Macro of the corner for the third ad: proves the quilting and the label.
tools: personal agent image tool (edit from reference) / steps: stock photo, brand label, 3 scenes

Repeatability

Same prompt and same reference, run 4 times.

run 1: label and quilt hold
run 2: label and quilt hold
run 3: label and quilt hold
run 4: label holds, quilt denser than source
the rerun prompt, verbatim (same prompt and same reference as the hero)Place this exact SOMNA mattress, same hexagon quilted top, dark knit side panel and white SOMNA label, on a simple platform base in a bright airy minimalist bedroom with soft morning window light from the left, pale oak floor, linen curtains, white bedding. Photorealistic commercial e-commerce hero photograph, whole mattress and its side label clearly visible.
Template

Place this exact [product], with the same [pattern], proportions and [label], on [scene], [light], photorealistic commercial photo, [focal rule]. Reference: branded source image. Keep the reference fixed, change only the bracket parts.

Result: SOMNA label present and readable at zoom in 4 of 4; side panel pattern in 4 of 4; quilt pattern spacing drifts in run 4 (denser hexagons), so 3 of 4 hold the quilt closely. Fix for a real project: give the quilt macro as a second reference to lock the stitch pattern.
