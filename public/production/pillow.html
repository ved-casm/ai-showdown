Brief to result

Invented brief, written the way a marketing partner would send it.

Brief (fictional)

Objective: lift add-to-cart on the TESSEL striped pillow PDP and give paid social 3 ad angles.
Audience: 28-45, buys bedding online, cares about feel and look.
Placements: PDP hero (16:9 desktop, 4:5 mobile), 1:1 and 9:16 social, wide banner.
Must hold: stripe pattern, woven TESSEL label, honest "concept" tag.

Decisions I made

  1. Daylight bedroom for the PDP hero: calm, pattern reads clearly, label visible.
  2. Warm evening scene for lifestyle and one ad: emotion, not specs.
  3. Macro detail for the third ad: proves the weave and the label.
tools: personal agent image tool (edit from reference) / steps: stock photo, brand label, 3 scenes / time: about 3 minutes of generation, plus checks

Edit control

Five steps from one source image. Each step names what was wrong and what I asked for.

1 reference: branded source photo
2 base: reference placed in a new room
3a problem: real book title is readable on the nightstand
3b inpaint fix: book cover blanked, rest unchanged
4 outpaint: widened to 21:9 with room for text
5 img2img restyle: same scene at dusk
prompts: "blank the book cover, keep everything else identical" / "extend sideways to 21:9, keep the pillow exactly as is" / "restyle to blue-hour, keep composition". Honest note: in the outpaint the pillow came out smaller than in the source, so I would re-run for a banner; I kept it to show the real result.
concept / spec work

Repeatability

Same prompt and same reference, run 4 more times. Pass means the pattern and the readable label both hold.

run 1: pattern holds, label tiny and unreadable
run 2: pattern holds, label tiny and unreadable
run 3: pattern holds, label tiny and unreadable
run 4: pattern holds (denser stripes), label garbled
Template

Place this exact [product], with the same [pattern], proportions and [label], on [scene], [light], photorealistic commercial photo, [focal rule]. Reference: branded source image. Keep the reference fixed, change only the bracket parts.

Result: pattern and composition hold in 4 of 4, label readable in 0 of 4 (tiny or garbled). Fix for a real project: add the label as a second reference or paint it in at the finishing step.
